# V5 Test Checklist

1. Launch
- Desktop/browser/PowerPoint remains fully visible.
- No black or white full-screen background.
- Toolbar visible.

2. Cursor mode
- Select Cursor.
- Click and scroll in underlying application.
- Underlying app receives input.

3. Pen
- Select Pen.
- Draw at least 10 strokes.
- Existing screen remains visible.
- Toolbar remains visible.

4. Brush
- Draw multiple strokes.
- Existing screen remains visible.

5. Shapes
- Line
- Rectangle
- Square
- Circle

6. Tool switching
- Cursor -> Pen -> Cursor at least 10 times.

7. Toolbar
- Move toolbar.
- Draw repeatedly.
- Toolbar must never disappear behind overlay.

8. Undo / Redo / Clear

9. Exit
- Close button works.
- Ctrl+Shift+Q works while overlay has focus.

10. Relaunch
- No leftover overlay.
- Application starts cleanly.
